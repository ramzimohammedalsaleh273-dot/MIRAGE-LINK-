# MIRAGE LINK

برنامج Windows عربي لعرض شاشة هاتف Android عبر مسارين مستقلين: USB اختياري، أو Wi-Fi دون كابل USB ودون اتصال إنترنت أثناء الاستخدام.

## الاتصال عبر Wi-Fi فقط (Android 11 أو أحدث)

1. شغّل نقطة اتصال الهاتف.
2. في Windows اضغط **اختيار شبكة Wi-Fi**، ثم اتصل بنقطة اتصال الهاتف.
3. على الهاتف افتح **خيارات المطور** وفعّل **تصحيح أخطاء USB اللاسلكي**.
4. عند الاستخدام لأول مرة، اختر **الإقران باستخدام رمز** واترك نافذة الرمز مفتوحة.
5. في MIRAGE LINK اضغط **عرض عبر Wi-Fi** وأدخل الرمز الذي يظهر على الهاتف عند طلبه؛ يقبل البرنامج الأرقام العربية والهندية والفارسية ويحوّلها داخلياً إلى صيغة ADB القياسية.
6. يبحث البرنامج عن خدمة الاقتران والاتصال التي يعلنها Android، ويستخدم المنفذ الفعلي المكتشف تلقائياً. لا تحتاج إلى كتابة IP أو PORT.
7. بعد نجاح الاقتران، يحتفظ ADB بمفتاح الاقتران؛ في المرات التالية يكفي تشغيل التصحيح اللاسلكي والاتصال بالشبكة نفسها ثم الضغط على **عرض عبر Wi-Fi**. قد يطلب Android إعادة الاقتران إذا أزيل الكمبيوتر من الأجهزة المقترنة أو أعيد ضبط إعدادات التصحيح.

لا يلزم كابل USB في أي خطوة من مسار Wi-Fi، ولا يلزم إنترنت. لا تستخدم منافذ ثابتة؛ Android يعلن منافذ الاقتران والاتصال، وقد تتغير بين الجلسات.

### إذا لم يظهر الهاتف

- تأكد أن الهاتف والكمبيوتر على نقطة الاتصال نفسها، وأن التصحيح اللاسلكي مفعّل.
- في أول مرة اترك شاشة **الإقران باستخدام رمز** مفتوحة أثناء البحث.
- اسمح لـ ADB بالاتصال على الشبكات الخاصة في جدار حماية Windows إذا ظهرت مطالبة الحماية.
- بعض نقاط الاتصال أو إعدادات عزل العملاء تمنع اكتشاف mDNS أو اتصال الأجهزة المحلية؛ يلزم اختبار الشبكة الفعلية عند حدوث ذلك.
- لا يعني نجاح البناء الآلي أن الاتصال نجح على كل هاتف أو نقطة اتصال.

## الاتصال عبر USB (مسار مستقل اختياري)

- صِل الهاتف بكابل بيانات.
- فعّل تصحيح USB ووافق على رسالة الثقة في الهاتف.
- حدّد الجهاز في قسم USB واضغط **بدء عرض USB**.
- يستخدم هذا المسار ADB وscrcpy. لا يحتاج مسار USB إلى إعداد Wi-Fi، ولا يغيّر مسار Wi-Fi إعدادات USB.

## الجودة والأداء

- يلتقط scrcpy صورة الهاتف بدقتها الأصلية ما لم يحدد المستخدم حداً للحجم.
- معدل البت الأعلى يقلل آثار الضغط لكنه لا ينشئ تفاصيل غير موجودة في المصدر ولا يحول شاشة الهاتف إلى 2K أو 4K.
- H.265 خيار تجريبي وقد لا يدعمه مرمّز بعض الهواتف.
- لا يوجد ضمان ثابت لمعدل 60 إطاراً/ثانية؛ يتأثر الأداء بالهاتف والشبكة والكمبيوتر.

## متطلبات التشغيل

- Windows 10 أو Windows 11.
- ADB وscrcpy (مرفقان في حزمة Windows المحمولة).
- Android 11 أو أحدث لمسار تصحيح أخطاء USB اللاسلكي.
- يلزم أن تسمح الشبكة المحلية باكتشاف mDNS واتصال الأجهزة ببعضها.

## التطبيق المساعد التجريبي

يحتفظ المستودع بمشروع Android companion تجريبي وسير عمل لبنائه، لكنه ليس مطلوباً لمسار Wi-Fi الأساسي الموثق أعلاه. مسار Wi-Fi الأساسي يستخدم ميزة Android المدمجة **Wireless debugging** ولا يحتاج إلى تثبيت تطبيق مرافق.

## البناء والاختبار من المصدر

متطلبات بناء Windows: Python 3.10+.

```powershell
py -m pip install -e ".[dev]"
py -m pytest
```

لبناء نسخة Windows محمولة:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\\packaging\\build-windows.ps1"
```

يوجد سير عمل مستقل لبناء مشروع Android companion التجريبي باستخدام Java 17 وGradle.

## بنية الاتصال اللاسلكي

- اكتشاف خدمات Android عبر `adb mdns services`.
- الاقتران الأول عبر `adb pair` باستخدام رمز Android المؤقت.
- الاتصال اللاحق عبر `adb connect` إلى عنوان ومنفذ يعلنهما Android ديناميكياً.
- عرض الشاشة عبر scrcpy.
- لا يوجد منفذ Wi-Fi ثابت مفروض على الهاتف، ولا يحتاج المستخدم إلى إدخال IP:PORT يدوياً.
